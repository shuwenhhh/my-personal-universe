# Shuwen's Little Universe

A playful, hand-drawn personal portfolio built as a small interactive universe. The site combines a crayon-and-chalk visual style with selected AI projects, creative work, professional experience, and a photo gallery for my tuxedo cat.

## Highlights

- Interactive planet navigation from a single-page home screen
- Animated hand-drawn meteor sky
- AI project screen linking to AlphaEngine and DigestTool on GitHub
- Creative canvas featuring Catastrophe and MediStar
- Clickable cat character that opens a framed photo gallery
- Resume and experience section
- Responsive layouts and reduced-motion support

## Tech stack

- React 19
- Vite 6
- Phosphor Icons
- CSS animations and responsive layouts

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed by Vite.

## Build and test

```bash
npm run build
npm run test:sites
```

The production build is written to `dist/`.

## Project structure

```text
src/                 React interface and styling
public/              Artwork, cat photos, project images, and resume
worker/              Static hosting worker
scripts/             Build preparation scripts
tests/               Hosting smoke tests
```
